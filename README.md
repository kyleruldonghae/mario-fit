# Mario Fit

An offline gym-log web app (PWA): today's workout from a weekly plan, animated schematics of machine exercises, fast set-by-set logging with a rest timer, comparisons with previous sessions, pain-aware progression suggestions, and treadmill, recovery, nutrition and supplement tracking.

- All data is stored only on the device (IndexedDB). Nothing is sent anywhere.
- Install: open the site in Chrome on Android → menu → **Install app** / **Add to home screen**.
- Personal data is not part of this repository. Restore your own backup in **Settings → Backup → Restore backup**.
- Make regular backups (Settings → Full backup) and keep the file somewhere safe.

Run locally: `python -m http.server 8765` in this folder, then open http://localhost:8765.
